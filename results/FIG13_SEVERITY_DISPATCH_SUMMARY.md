# Figs. 13–14: 산업·주거 모선별 HB-MPS 이중 운용

기존 fig13_old와 메인 P1 코드는 변경하지 않았다. α=1.3 결과를 운전·차량 배치 Fig. 13과 전압 효과 Fig. 14로 분리했다.

## 모선 구성과 운용 규칙

- IEEE 33-bus의 산업부하 모선 9개를 유지하고, 나머지 부하 모선 23개는 주거부하로 설정했다. 혼합부하는 사용하지 않는다. Slack 1개 모선, 선로, 모선별 정격 P·Q는 유지한다. 산업·주거 부하는 각각의 실측 프로파일로 정규화해 시간별 scaling에 적용한다.
- 산업 모선별 임계값은 α×해당 모선의 168시간 평균 부하다. 초과량은 가정된 공급 허용량 대비 부족분이며 실제 미공급 전력은 아니다. 산업 모선에서 초과량>0일 때만 Mode 2가 우선한다. 저전압만으로는 출동하지 않으며 0.95 p.u.는 전압 성능 평가 기준이다.
- Mode 2는 초과량이 있는 산업 모선만 접속 후보로 삼는다. 해당 모선의 초과량과 0.95 p.u. 위반량을 각각 시간별 최대값으로 정규화한 뒤 0.5씩 가중하여 배치 순위를 정한다. HFC를 차량별로 먼저 투입하고 매 주입 후 AC를 다시 계산한다. ESS는 주 차량의 backup이다. 공급량은 모선별 잔여 초과량과 차량 가용 용량 중 작은 값이며, 전압 개선만을 위한 추가 공급은 하지 않는다.
- Mode 2가 없을 때에만 기존 P1의 가격·SOC 조건에 따른 Mode 1을 허용한다. 주 차량 ESS 출력은 주거부하 모선에 AC 주입한다. 주거 모선의 가격 신호가 같으므로 가장 낮은 기준 전압의 주거 모선을 접속 위치로 정했다. Mode 1 발동에 주거 전압 임계는 사용하지 않는다.
- PV ESS 충전과 P2G 소비는 PV 연결 Bus 7의 부하로, 계통 ESS 충전은 주거 Bus 9의 부하로 반영한다. 충전 부하는 별도 요소로 두어 시간별 주거 scaling을 중복 적용하지 않았다. 차량은 매시간 재배치할 수 있으며 실제 이동 시간은 모델링하지 않았다.
- HB-MPS의 원자료 kWh→IEEE 계통 MW 환산은 기존 검증과 동일하게 산업 모선 정격 MW/입력 산업부하 최대 kWh를 모든 공급·충전에 적용한다. HFC/ESS 정격, 효율, SOC·LOH, 수소 이동 소비·보충 및 Mode 1 가격 조건은 기존 P1과 같다. 계산상 부하 초과량을 물리적 미공급 전력으로 간주하거나 그 전체에 VOLL 편익을 자동 부여하지 않는다.

α=1.3의 Fig. 13은 (a) 합산 산업부하·허용량, (b) Mode 1·2 운용 시간, (c) 차량별 실제 접속 모선을 표시한다. Fig. 14는 (a) 기준 최악 시간의 모선별 전압·접속 모선, (b) 33개 모선의 전압 시계열, (c) 지원 후−기준 모선별 전압 변화를 표시한다. α=1.5의 기존 6패널 결과는 fig13_2로 별도 보존한다. 전압 변화의 음수는 충전 등으로 전압이 낮아진 경우도 보여 준다. 0.95 p.u. 선은 출동 조건이 아닌 전압 평가 기준이다.
전체 33개 모선의 0.95 p.u. 미만 시간은 Mode 1·2 지원 후에도 남는다. 주거 저전압만으로 Mode 2가 발동하지 않으며, Mode 1은 경제성·SOC 조건이 맞을 때만 공급하므로 모든 저전압을 해소하지 않는다.

**논문 조건 선택:** 두 α의 전체 저전압 시간은 같다. 산업 초과 조건은 α=1.3에서 39시간, α=1.5에서 8시간이다. α=1.5는 Mode 1을 23시간 보여 주며 α=1.3의 15시간보다 많다. 다만 누적 전압 위반은 α=1.5가 10.576 p.u.·bus·h로 α=1.3의 10.023보다 크다. 비상 공급 원자료 에너지도 α=1.5는 1.197 MWh, α=1.3은 26.845 MWh이다. 이중 운용을 적은 비상 출동과 자원 소비로 보여 주는 대표 그림에는 α=1.5가 적합하고, 더 큰 전압 개선 효과를 검토할 때는 α=1.3을 함께 제시해야 한다. 두 경우 모두 남는 저전압을 명시해야 한다.
